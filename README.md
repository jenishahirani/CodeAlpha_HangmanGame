# CodeAlpha Task 1: Hangman Game

## Project Overview
A simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Random word selection from five predefined words.
- Guess one letter at a time.
- Maximum of six incorrect guesses.
- Displays correctly guessed letters.
- Shows win or loss results.

## Technologies Used
- Python
- Random module
- Lists and strings
- While loops
- If-else statements

## How to Run
1. Install Python.
2. Download `hangman.py`.
3. Open a terminal in the file's folder.
4. Run `python hangman.py`.
